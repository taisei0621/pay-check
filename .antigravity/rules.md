# Antigravity 行動規範 (Project Rules)

## 開発の原則
1. **計画優先 (Plan-First)**: いきなりコードを編集せず、必ず変更計画（plan.md）を提示してユーザーの承認を得ること。
2. **型安全の徹底**: TypeScriptの `any` 型は使用禁止。適切な型定義を行うこと。
3. **関心の分離**: UIコンポーネント（React）とデータ取得・ロジック（Supabase等）は可能な限り分離し、純粋関数としてテスト可能にすること。
4. **シンプルさの維持**: 複雑なアカウント認証は作らず、イベントIDベースのURLアクセス（匿名アクセス）を優先すること。
5. **テストの配備**: 新しいロジックを追加した際は、Vitestによる単体テストも同時に記述・実行すること。
